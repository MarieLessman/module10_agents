## Pip, the Palm Street Bakery assistant

## About:
Pip is a small FAQ assistant for a made-up bakery that answers questions about hours, parking, wifi, and delivery by looking them up in a tool class. Everything about it is mock: the bakery and its answers are invented, and Pip's replies come from simple keyword rules instead of real AI. Requests that mention refunds, complaints, allergies, or custom cakes are passed to a team member, because those need a human to make a judgment call or take responsibility. If Pip used real customer data, it could give an out-of-date answer, like wrong hours or an allergy answer that actually harms someone.
